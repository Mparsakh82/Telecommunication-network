# دستور کار: برقراری تماس VoIP بین ایستگاه وب و ایستگاه موبایل

## ۱. هدف
برقراری تماس صوتی روی شبکه IP بین دو ایستگاه (یک ایستگاه وب روی کامپیوتر و یک ایستگاه موبایل روی مرورگر گوشی) و بررسی نحوه کار سیگنالینگ، انتقال صدا (RTP) و کیفیت تماس (RTT، جیتر، اتلاف بسته).

## ۲. مفاهیم پایه
- **سیگنالینگ:** تبادل پیام‌های برقراری و قطع تماس (offer، answer، ICE، hangup). در این پروژه با WebSocket روی یک سرور Node.js انجام می‌شود (معادل پیام‌های INVITE / 200 OK / BYE در SIP).
- **مدیا:** صدا با WebRTC و کدک Opus به‌صورت رمزشده (SRTP) و مستقیم بین دو ایستگاه ارسال می‌شود.
- **ICE:** یافتن مسیر ارتباط بین دو ایستگاه (در شبکه محلی با آدرس‌های محلی).

## ۳. وسایل و نرم‌افزار
- یک کامپیوتر (macOS یا Windows) و یک گوشی، متصل به **یک وای‌فای** (VPN خاموش)
- Node.js نسخه LTS (nodejs.org)
- مرورگر Chrome روی کامپیوتر و Safari/Chrome روی گوشی
- Wireshark (برای ثبت بسته‌ها)

## ۴. ساختار پروژه
```
voip-web/
├── package.json
├── server.js
└── public/
    └── index.html
```

## ۵. مراحل اجرا
1. نصب Node.js و بررسی آن در ترمینال:
   ```
   node -v
   npm -v
   ```
2. ورود به پوشه پروژه و نصب وابستگی‌ها:
   ```
   cd voip-web
   npm install
   ```
3. اجرای سرور:
   ```
   npm start
   ```
   خروجی باید آدرس HTTP (پورت 8080) و آدرس‌های HTTPS (پورت 8443) را نشان دهد.
4. **ایستگاه وب:** در Chrome کامپیوتر آدرس `http://localhost:8080` را باز کنید، نام `web` را وارد کنید و «ورود به شبکه» را بزنید.
5. **ایستگاه موبایل:** در گوشی آدرس `https://IP-کامپیوتر:8443` را باز کنید (IP از خروجی ترمینال)، هشدار گواهی را رد کنید (در آیفون: Show Details ← visit this website)، نام `mobile` را وارد کنید و ورود بزنید.
6. میکروفون را در هر دو مرورگر Allow کنید.

> میکروفون در گوشی فقط روی HTTPS کار می‌کند؛ به همین دلیل آدرس 8443 برای گوشی لازم است.

## ۶. آزمایش‌ها
1. **تماس وب ← موبایل:** از ایستگاه وب روی «تماس» بزنید، در گوشی «پاسخ» دهید و ۳۰ ثانیه صحبت کنید.
2. **تماس موبایل ← وب:** همین کار را در جهت عکس انجام دهید.
3. **قطع تماس:** تماس را از هر دو طرف قطع کنید و رفتار ایستگاه مقابل را ببینید.
4. **ثبت کیفیت:** حین تماس مقادیر RTT، Jitter، Packets lost و Codec را که روی صفحه نمایش داده می‌شود یادداشت کنید.
5. **ثبت بسته‌ها:** Wireshark را روی کارت وای‌فای کامپیوتر اجرا کنید (فیلتر `websocket || stun || dtls || udp`) و حین تماس چند ثانیه ضبط کنید.

## ۷. گزارش (موارد خواسته‌شده)
- تصویر صفحه هر دو ایستگاه حین تماس و جدول مقادیر RTT، جیتر، اتلاف و کدک
- تصویر Wireshark و توضیح مراحل: سیگنالینگ (WebSocket)، یافتن مسیر (STUN/ICE)، رمزنگاری (DTLS) و انتقال صدا (RTP/SRTP روی UDP)
- مقایسه سیگنالینگ این پروژه با SIP (INVITE، 180 Ringing، 200 OK، ACK، BYE)
- پاسخ به این پرسش‌ها:
  1. چرا مدیا روی UDP ارسال می‌شود، نه TCP؟
  2. جیتر و اتلاف بسته چه تأثیری بر کیفیت صدا دارند؟
  3. چرا مرورگر برای میکروفون به HTTPS نیاز دارد؟
  4. تفاوت این روش با circuit switching چیست؟

## ۸. عیب‌یابی
| مشکل | راه‌حل |
|------|--------|
| `npm` شناخته نمی‌شود | Node.js را نصب کنید و ترمینال را ببندید و دوباره باز کنید |
| `EADDRINUSE` | سرور قبلی را ببندید: `pkill -f "node server.js"` (مک) |
| `Cannot find module 'ws'` | در پوشه پروژه `npm install` بزنید |
| `index.html not found` | فایل را داخل پوشه `public` بگذارید |
| گوشی صفحه را باز نمی‌کند | یک وای‌فای بودن، خاموش بودن VPN و فایروال مک را بررسی کنید |
| میکروفون در گوشی کار نمی‌کند | از آدرس `https://...:8443` استفاده کنید و اجازه میکروفون را بدهید |

## ۹. بارگذاری در GitHub
فایل `.gitignore` پروژه فایل‌های `node_modules/` و `cert.json` را نادیده می‌گیرد. دستورها:
```
git init
git add .
git commit -m "VoIP web/mobile stations"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```
GitHub سرور را اجرا نمی‌کند؛ برای اجرا، پروژه را clone کنید و مراحل بخش ۵ را انجام دهید (یا از GitHub Codespaces و در تب Ports پورت 8080 را Public کنید).
